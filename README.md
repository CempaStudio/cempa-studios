## Proyectos del portafolio

### Taquería El Sabor Mexicano

**Prototipo conceptual para restaurante.** Incluye presentación visual, menú digital, navegación responsive y modo claro/oscuro.

- **Tecnologías:** HTML5, CSS3, JavaScript.
- [Ver demostración](https://cempastudio.github.io/cempa-studios/demos/taqueria-el-sabor-mexicano/)

### Boutique Luna

**Prototipo conceptual de catálogo de moda.** Incluye fichas de productos, carrito demostrativo, navegación responsive y opciones de idioma.

- **Tecnologías:** HTML5, CSS3, JavaScript.
- [Ver demostración](https://cempastudio.github.io/cempa-studios/demos/boutique-luna/)

### El Búho Político MX

**Proyecto editorial desarrollado para un cliente.** A diferencia de los dos prototipos anteriores, el sistema original utiliza **PHP y MySQL** para publicar, editar, organizar y administrar contenido mediante distintos niveles de acceso. También integra carga de imágenes, videos, búsqueda y filtros, así como información de fecha, clima y tipo de cambio USD/MXN.

- **Tecnologías del sistema original:** HTML5, CSS3, JavaScript, PHP y MySQL.
- [Ver demostración pública](https://cempastudio.github.io/cempa-studios/demos/buho-politico-mx/)

**Importante:** la demostración de El Búho Político MX es una adaptación estática con contenido de prueba. No es el sitio oficial, no incorpora el backend original ni permite acceder al panel administrativo. **El código completo y la base de datos del proyecto para el cliente no se distribuyen.**

## Tecnologías y herramientas

**Frontend:** HTML5, CSS3, JavaScript, diseño responsive.

**Backend y bases de datos (experiencia de proyecto):** PHP, MySQL.
